Создал новый проект Windows Forms в Visual Studio.
На главной форме создал интерфейс с использованием следующих элементов управления:
- Панель (Panel), закрепленная слева с помощью свойства Dock.
- Рабочая область (Panel), закрепленная на оставшейся части окна с помощью свойства Dock.
Добавил на рабочую область текстовое поле (TextBox) и кнопку (Button).
- Настроил свойства Anchor для этих элементов, чтобы они изменяли размер и оставались пропорционально размещенными при изменении размеров окна.
Запустил приложение и протестируйте адаптацию элементов управления при изменении размеров окна.
